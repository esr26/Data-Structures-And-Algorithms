When to Use
Use shortest paths whose edge costs are only 0 or 1.

How It Works
Example: A->B costs 0 and B->C costs 1: distance A to C is 1.
1. Set source distance 0 in a deque.
2. Pop the front state.
3. Relax a zero-cost edge and push its neighbor to the front.
4. Relax a one-cost edge and push to the back.
5. Skip non-improving distances.

Quick Facts
O(V+E) time, O(V+E) graph/queue storage. Pitfall: a normal FIFO queue loses weighted ordering.
