When to Use
Use to rotate an array in place by k positions.

How It Works
Example: Right rotate [1,2,3,4] by 1 to [4,1,2,3].
1. Reduce k modulo array length.
2. Reverse the whole array.
3. Reverse the first k elements.
4. Reverse the remaining elements.
5. Read the rotated array.

Quick Facts
O(n) time, O(1) space. Pitfall: normalize k and handle an empty array before modulo.
