When to Use
Use to find the largest number dividing two integers.

How It Works
Example: gcd(18,12)=6.
1. Set a=18 and b=12.
2. Replace (a,b) with (b,a mod b), giving (12,6).
3. Repeat to (6,0).
4. Return nonzero a=6.

Quick Facts
O(log min(a,b)) time, O(1) iterative space. Pitfall: handle zeros and negative inputs consistently.
