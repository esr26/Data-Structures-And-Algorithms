When to Use
Use when equality counts or character frequencies matter more than positions.

How It Works
Example: For 'aab', counts are a:2 and b:1.
1. Create an empty count map.
2. Read a; set a to 1.
3. Read a again; set a to 2.
4. Read b; set b to 1.
5. Compare or use the final counts.

Quick Facts
O(n) expected time, O(k) space for k distinct keys. Pitfall: distinguish counts from set membership.
