When to Use
Use when closing tokens must match the latest opening token, or nested text must be decoded.

How It Works
Example: For '([])', each closer matches the top opener.
1. Push opening tokens.
2. On a closing token, compare it with the stack top.
3. Pop only a valid match.
4. Reject a mismatch or an empty stack.
5. Accept when no openers remain.

Quick Facts
O(n) time, O(n) space. Pitfall: stack must be empty at the end.
