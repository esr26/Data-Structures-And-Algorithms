Use when a monotonic order lets one half be discarded after each comparison.

How It Works
Example: Find 7 in [1,3,5,7,9].
1. Set low=0 and high=4.
2. Check middle value 5.
3. Since 7 is larger, move low past the middle.
4. Check 7 and return its index.
5. Stop if the interval becomes empty.

Quick Facts
O(log n) time, O(1) space. Pitfall: update bounds so the interval strictly shrinks.
