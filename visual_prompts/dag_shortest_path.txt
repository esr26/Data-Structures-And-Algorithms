When to Use
Use weighted shortest paths in a directed acyclic graph, even with negative edges.

How It Works
Example: A->B cost 2, A->C cost 5, B->C cost 1: A to C costs 3.
1. Find a topological order.
2. Set source distance to 0 and others to infinity.
3. Process nodes in that order.
4. Relax outgoing edges once each.
5. Update C via B to cost 3.

Quick Facts
O(V+E) time, O(V) space. Pitfall: only works when the graph is acyclic.
