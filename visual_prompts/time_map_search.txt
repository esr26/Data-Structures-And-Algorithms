When to Use
Use to retrieve the newest stored value at or before a query time.

How It Works
Example: Records (1,'a'), (4,'b'); query 3 returns 'a'.
1. Append timestamped values in increasing order.
2. Binary search for first time greater than query.
3. Step back one record.
4. Return its value, or empty if none exists.

Quick Facts
O(log n) query per key, O(n) storage. Pitfall: insertion timestamps must stay sorted.
