When to Use
Use to find edges whose removal disconnects an undirected graph.

How It Works
Example: Chain A-B-C has bridge edges A-B and B-C.
1. DFS and assign discovery times.
2. Track the earliest reachable discovery time low[u].
3. Return low values from child subtrees.
4. For tree edge u-v, if low[v] > disc[u], mark a bridge.
5. Skip only the parent edge when exploring.

Quick Facts
O(V+E) time, O(V) auxiliary space. Pitfall: back edges must update low using discovery time.
