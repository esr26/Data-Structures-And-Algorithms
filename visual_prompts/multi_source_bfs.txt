When to Use
Use when several starting cells or vertices spread simultaneously.

How It Works
Example: Line cells 0,1,2 with sources at 0 and 2: middle distance is 1.
1. Enqueue every source with distance 0.
2. Mark sources visited.
3. Process the queue by layers.
4. Set each unseen neighbor to parent distance+1.
5. Middle cell first receives distance 1.

Quick Facts
O(V+E) time, O(V) space. Pitfall: enqueue all sources before expansion.
