When to Use
Use when a continuous threshold is monotonic and an approximate answer is accepted.

How It Works
Example: Between stations at 0 and 10, one new station yields maximum gap 5.
1. Choose low/high bounds for the maximum allowed gap.
2. For middle gap d, count required extra stations.
3. If count exceeds budget, raise d.
4. Otherwise lower d.
5. Stop at required precision.

Quick Facts
O(n log(R/epsilon)) time, O(1) extra space. Pitfall: exact multiples need careful station-count math.
