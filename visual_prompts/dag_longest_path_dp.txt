When to Use
Use prerequisite DAGs where the answer is earliest finish or longest weighted chain.

How It Works
Example: A duration 2 precedes B duration 3: B finishes at time 5.
1. Topologically process zero-indegree courses.
2. Set A's finish to its duration 2.
3. Propagate finish[A]+duration[B] to B.
4. Take max when B has multiple prerequisites.
5. Return the maximum finish time.

Quick Facts
O(V+E) time, O(V) state space. Pitfall: take max over prerequisites, not sum, when tasks can run in parallel.
