When to Use
Use when a window property can be repaired by moving the left boundary.

How It Works
Example: For [2,3,1,2] and target sum 5, [2,3] has length 2.
1. Expand right and update the window state.
2. When the positive-number sum reaches 5, record length.
3. Shrink left while the condition still holds.
4. Continue expanding to compare later windows.

Quick Facts
O(n) time, O(1) space for sums; constraints like positivity make shrinking valid. Pitfall: negative values break simple sum monotonicity.
