When to Use
Use when values fall in a known index range and in-place marking is allowed.

How It Works
Example: In [3,4,-1,1], first missing positive is 2.
1. For each position, move valid value x to index x-1.
2. Continue until the current value is invalid or already placed.
3. Scan indices from left to right.
4. The first index without value index+1 gives the answer.

Quick Facts
O(n) time, O(1) extra space. Pitfall: guard duplicates to avoid endless swaps.
