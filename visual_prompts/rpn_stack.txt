When to Use
Use when postfix expressions can be evaluated without precedence rules.

How It Works
Example: Tokens 2,3,+ evaluate to 5.
1. Push 2.
2. Push 3.
3. On +, pop right operand 3 then left operand 2.
4. Apply 2+3 and push 5.
5. Return the final stack value.

Quick Facts
O(n) time, O(n) space. Pitfall: subtraction and division depend on pop order.
