When to Use
Use for the maximum sum of a nonempty contiguous subarray.

How It Works
Example: For [-2,1,-3,4,-1,2], best is [4,-1,2] with sum 5.
1. Start current and best at the first value.
2. At each value, choose it alone or extend current.
3. For 4, restart because the prior sum hurts.
4. Extend through -1 and 2 to reach 5.
5. Return the best seen.

Quick Facts
O(n) time, O(1) space. Pitfall: initialize from the first element so all-negative arrays work.
