When to Use
Use when a score must be calculated for every substring and can update as the end extends.

How It Works
Example: For 'aba', substring 'ab' has counts a:1,b:1 and score max-min=0.
1. Choose each start index.
2. Reset frequency counts.
3. Extend the end index one character at a time.
4. Update only the new character's count.
5. Compute the score and add it to the total.

Quick Facts
O(n²·k) time when each score scans k character counts; O(k) space. Pitfall: reset counts for each new start.
