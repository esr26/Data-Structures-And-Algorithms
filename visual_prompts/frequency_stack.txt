When to Use
Use when pop should return the most frequent value, breaking ties by recency.

How It Works
Example: Push 5,7,5; pop returns 5.
1. Track frequency of each value.
2. Place each push in a bucket for its new frequency.
3. Track the highest active frequency.
4. Pop the newest value from that bucket.
5. Reduce its frequency and highest bucket if empty.

Quick Facts
O(1) average per operation, O(n) space. Pitfall: tie-breaking is most recent among equal frequencies.
