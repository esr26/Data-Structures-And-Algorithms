When to Use
Use to test whether a graph can be split into two groups with edges only across groups.

How It Works
Example: Path A-B-C can color A red, B blue, C red.
1. Start an uncolored component with red.
2. Give every neighbor the opposite color.
3. Continue with BFS or DFS.
4. Reject an edge connecting same-color endpoints.
5. Repeat for disconnected components.

Quick Facts
O(V+E) time, O(V) space. Pitfall: odd cycles break bipartiteness.
