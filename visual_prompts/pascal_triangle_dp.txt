When to Use
Use to generate binomial-coefficient rows from earlier rows.

How It Works
Example: Rows start [1], [1,1], then [1,2,1].
1. Create first row [1].
2. For each new row, put 1 at both ends.
3. Fill interior position j from two parents above.
4. For row 3, add 1+1 to get middle 2.
5. Repeat to requested row count.

Quick Facts
O(r²) time and O(r²) output space for r rows. Pitfall: only interior entries have two parents.
